# AIOT 工具（Tool）流程图

描述用户在提示词编辑场景下，通过草稿编辑态管理工具配置的完整流程。**工具面板与提示词不做联动**：加入/移除工具都不改动提示词，用户需在提示词中自行写明何时调用工具，且**调用的工具范围必须落在当前端点可用工具列表内**。

> 职责分工：
> - **工具服务（麒哥）**：提供全局工具全集，以及当前端点「已用工具」列表（工具列表初始来源）。
> - **平台后端（威哥）**：负责智能体数据（含提示词 + 工具列表及运行时配置）的存储；画布真实执行时也从平台后端取数。

## 主流程泳道图

```mermaid
sequenceDiagram
    participant U as 用户
    participant FE as 前端
    participant Tool as 工具服务(麒哥)
    participant PF as 平台后端(威哥)
    participant Canvas as 画布执行引擎

    U->>FE: 点击「工具配置」
    FE->>Tool: 请求当前端点已用工具列表
    Tool-->>FE: 返回已用工具行 [{id,name,desc,tool}]
    FE-->>U: 展示工具面板（已有工具则自动选中第一个）

    U->>FE: 点击「添加工具」
    FE->>FE: 创建空草稿（不写入usedTools）
    FE-->>U: 右侧展示编辑表单

    U->>FE: 选择工具（自定义下拉）
    FE->>Tool: 读取全局工具全集（本地缓存）
    FE-->>U: 下拉展示工具名+描述两行

    U->>FE: 填写名称/描述/运行时配置后点「确定」
    FE->>FE: 校验(名称必填+工具必选)→通过→写入usedTools+toolRuntimeConfig
    FE-->>U: 左侧列表更新，右侧保持编辑态

    U->>FE: 在提示词中自行书写「何时调用某工具」
    U->>FE: 点击保存
    FE->>PF: 保存智能体数据（提示词+工具列表及其运行时配置）
    PF-->>FE: 保存成功

    Note over Canvas: 画布真实执行阶段
    Canvas->>PF: 读取提示词与工具运行时配置
    PF-->>Canvas: 返回配置数据
    Canvas->>Canvas: 按运行时配置真实执行工具
```

## 草稿编辑态流程

```mermaid
flowchart TB
    Open[点击「工具配置」打开面板] --> HasTools{已有工具?}
    HasTools -->|是| AutoSelect[自动选中第一个工具<br/>左侧蓝色高亮+右侧展示详情]
    HasTools -->|否| Empty[右侧提示「暂无工具...」<br/>左侧为空]

    AutoSelect --> EditOrAdd{操作选择}
    Empty --> Add[点击「添加工具」]

    EditOrAdd -->|点击列表项| EditRow[拷贝已保存行为草稿<br/>进入编辑态]
    EditOrAdd -->|点击「添加工具」| Add

    Add --> CreateDraft[创建空草稿<br/>id=acGenToolId, name='', tool='']
    CreateDraft --> FillForm[右侧展示编辑表单<br/>名称/描述/选择工具/运行时配置]

    EditRow --> FillForm

    FillForm --> Confirm{点击「确定」}
    FillForm --> Cancel{点击「取消」}
    FillForm --> SwitchRow{切换列表项}

    Confirm --> Validate{校验}
    Validate -->|名称为空| ErrName[名称输入框红框+红字提示]
    Validate -->|工具未选| ErrTool[下拉红框+红字提示]
    Validate -->|通过| Commit[写入usedTools+toolRuntimeConfig<br/>描述为空则填入默认描述]

    Commit --> KeepEdit[保持编辑态<br/>左侧列表更新+右侧继续展示]
    KeepEdit --> FillForm

    ErrName --> FillForm
    ErrTool --> FillForm

    Cancel --> Discard[丢弃草稿]
    Discard --> HasTools2{还有工具?}
    HasTools2 -->|是| AutoSelect
    HasTools2 -->|否| Empty

    SwitchRow --> DiscardDraft[未确认草稿丢弃]
    DiscardDraft --> EditRow
```

## 面板内交互流程

```mermaid
flowchart TB

    Show --> Add{点击「添加工具」?}
    Add -->|创建空草稿| AddDraft[右侧展示空表单<br/>名称输入框自动聚焦]
    AddDraft --> Show

    Show --> Select{点击列表项?}
    Select -->|拷贝为草稿| EditRow[右侧展示该工具编辑表单]
    EditRow --> Show

    Show --> Remove{列表项悬停点击删除?}
    Remove -->|二次确认弹窗| RemoveDo[从usedTools剔除+删除toolRuntimeConfig]
    RemoveDo --> HasMore{还有工具?}
    HasMore -->|是| Show
    HasMore -->|否| EmptyShow[右侧展示空态提示]

    Show --> Cfg{点击「解析并配置翻译」?}

    Cfg -->|名称已填| Modal[打开设备状态翻译弹窗<br/>acDeviceStateModal rowId, onDone, dispName]

    CfgBack --> Show

    Show --> Confirm{点击「确定」?}
    Confirm -->|校验不通过| ShowErr[红字提示必填项]
    ShowErr --> Show
    Confirm -->|校验通过| Commit[写入usedTools+toolRuntimeConfig<br/>保持编辑态]
    Commit --> Show

    Show --> Cancel{点击「取消」?}
    Cancel --> Discard[丢弃草稿,回落到第一个工具]
    Discard --> Show
```

## 关键说明

- **草稿编辑态**：所有编辑操作先写入 `draft` 对象，点「确定」经校验后才提交到 `AC.usedTools`；未确定即切走则草稿丢弃。
- **数据模型**：`AC.usedTools` 为对象数组 `[{id, name, desc, tool}]`，行 id 由 `acGenToolId()` 生成；`AC.toolRuntimeConfig` 和 `AC.deviceStateDraft` 均以行 id 为键。
- **入口位置**：「工具配置」位于提示词编辑区「任务规划器」行右侧、「编写教程」左侧，纯文字无图标。
- **初始态**：打开面板自动选中第一个工具（蓝色高亮+右侧详情）；无工具时右侧展示空态提示，左侧为空。
- **确定后保持编辑态**：提交成功后 draft 不置空，右侧继续展示当前工具内容，左侧列表同步更新。
- **描述自动填充**：点确定时若描述为空，自动写入所选工具的默认描述。
- **内联校验**：名称/工具未填时字段下方红字提示+红框，输入/选择后自动清除。
- **删除回落**：删除后右侧回落到列表第一个工具（无工具则空态提示）。
- **取消回落**：取消后回落到列表第一个工具（无工具则空态提示）。
- **工具与提示词不联动**：加入/移除工具都**不改动提示词**；用户需在提示词中写明**何时用什么工具**，且所写工具**必须落在当前端点可用工具列表内**。
- **运行时配置**：始终展示（无论是否已选择工具），点击「解析并配置翻译」进入设备状态翻译弹窗（回调式写回）。
- **数据存储与取数**：智能体数据（提示词 + 工具列表及运行时配置）统一存储在**平台后端（威哥）**；画布真实执行时从**平台后端（威哥）**读取。
