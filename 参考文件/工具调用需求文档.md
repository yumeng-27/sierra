# 工具调用需求文档

本文档描述「工具配置面板」的实现链路与交互细节，不含背景与目标。

## 一、入口与数据

- **入口**：提示词编辑区「任务规划器」行右侧，「编写教程」左侧的「工具配置」文字链接（`data-ac-tool-panel`），点击打开工具配置面板抽屉（宽 820px）。
- **全局工具全集** `AC.tools`：当前端点可用工具全集，由工具服务（麒哥）提供。每项结构：
  - `name`：工具名
  - `desc`：工具描述
  - `params`：入参列表 `[{k, t}]`
  - `ret`：返回说明
  - `hasRuntimeConfig`：是否支持运行时配置（可选）
- **已添加工具行** `AC.usedTools`：对象数组，每项结构：
  - `id`：行唯一标识，由 `acGenToolId()` 生成（`'ut-'` + 时间戳 36 进制 + 随机串）
  - `name`：自定义工具名称（必填，用户输入）
  - `desc`：自定义描述（可空，留空则点确定时自动填入所选工具的默认描述）
  - `tool`：底层工具名（从全局工具全集中选择）
- **运行时配置** `AC.toolRuntimeConfig`：`{ [行id]: 配置JSON字符串 }`，键为行 id。
- **设备状态翻译草稿** `AC.deviceStateDraft`：`{ [行id]: { deviceId, token, json, rows } }`，键为行 id。
- **持久化**：`usedTools`、`toolRuntimeConfig` 已纳入智能体配置存储（AGENT_CFG_KEYS）。

## 二、草稿编辑态模型

工具面板采用**草稿编辑态**模型：编辑操作（新建/修改）先写入内部 `draft` 对象，点「确定」经校验后才提交到 `AC.usedTools`；未确定即切走（选其他行/关闭面板）则草稿丢弃。

- **draft 对象**：`{ id, name, desc, tool, runtime, isNew, errName?, errTool? }`，为编辑态单一数据源。
- **activeId**：当前高亮的已保存行 id，驱动列表高亮样式。
- **editRow(id)**：将已保存行拷贝为草稿（`isNew:false`），进入编辑态。
- **commitDraft()**：校验 → 构造 payload → 写入 `AC.usedTools`（覆盖或新增）→ 写入/删除 `toolRuntimeConfig` → 保持编辑态（draft 不置空，右侧继续展示）。
- **取消**：丢弃草稿，回落到列表第一个工具（无工具则右侧展示空态提示）。

## 三、面板布局

- **标题栏**：左侧标题「工具」；右侧「添加工具」按钮（`data-tool-add-btn`）。无关闭叉，靠遮罩 / ESC 关闭。
- **主体**：左列表（220px，`data-tool-list`）+ 右详情（`data-tool-detail`，flex 纵向）。
  - 左列表：展示已添加工具行，每项双行（主标题=自定义名称 || 底层工具名，副标题=自定义描述 || 底层默认描述），悬停显示删除图标。初始态（无工具）左侧为空，不在左侧显示提示。
  - 右详情：展示当前草稿的编辑表单，或空态提示文字。
- **初始态**：打开面板时若已有工具，自动选中并展示第一个工具的详情（蓝色高亮 + 右侧表单）；若无工具，右侧展示「暂无工具，点击右上角「添加工具」开始配置。」，左侧为空。

## 四、交互细节

### 1. 添加工具

- 点击「添加工具」按钮，创建空草稿 `{ id:acGenToolId(), name:'', desc:'', tool:'', runtime:'', isNew:true }`，不写入 `AC.usedTools`。
- 右侧展示编辑表单，名称输入框自动聚焦。
- 未确定即切走（选其他行/关闭面板），草稿丢弃。

### 2. 选择工具（自定义下拉）

- 原生 select 无法展示富文本，改为自定义下拉面板（`data-tool-select-wrap / btn / list / opt`）。
- 点击下拉按钮（`data-tool-select-btn`）切换下拉显隐；点击面板其他区域收起。
- 下拉项（`data-tool-opt`）双行展示：工具名 + 默认描述。
- 选中后设置 `draft.tool` 并重绘详情（影响运行时配置区提示等）。
- 点击空白关闭下拉。

### 3. 确定与取消

- **确定**（`data-tool-confirm`）：
  1. 内联校验：名称为空 → `draft.errName=true`，输入框红框 + 下方红字「请输入工具名称」；工具未选 → `draft.errTool=true`，下拉红框 + 下方红字「请选择工具」。
  2. 校验不通过则 `rerender()` 展示红字提示，不写入。
  3. 校验通过：构造 payload `{ id, name, desc, tool }`，`findIndex` 覆盖或 push 进 `AC.usedTools`；运行时配置非空写入 `AC.toolRuntimeConfig[draft.id]` 否则删除。
  4. 描述为空时自动填入所选工具的默认描述（`findTool(draft.tool).desc`）。
  5. 提交后**保持编辑态**：`draft.isNew=false`，清 err，`activeId=draft.id`，右侧继续展示当前工具内容。
- **取消**（`data-tool-cancel`）：丢弃草稿，回落到列表第一个工具；无工具则右侧展示空态提示。
- **输入清除 err**：用户在名称输入框输入内容后，若 `draft.errName` 为 true 且内容非空，自动清除红字并重绘；选择工具后自动清除 `draft.errTool`。

### 4. 列表交互

- **选中**：点击列表项（`data-tool-item`）调用 `editRow(id)`，拷贝已保存行为草稿进入编辑态。未确认的草稿被丢弃。
- **删除**：列表项悬停显示删除图标（`data-tool-remove`），点击弹出二次确认弹窗（`confirmModal`），确认后：
  1. 从 `AC.usedTools` 剔除该行并删除 `AC.toolRuntimeConfig[id]`。
  2. 右侧回落到列表第一个工具（无工具则展示空态提示）。
- **列表双行展示**：主标题 = `(row.name||bt.name)||'未命名工具'`，副标题 = `(row.desc||bt.desc)`（副标题为空则不显示）。

### 5. 运行时配置区

- **始终展示**：无论是否已选择工具，运行时配置区均可见可编辑。
- 包含「解析并配置翻译」入口（`data-panel-config`）与配置文本框（`data-tool-runtime`）。
- 点击「解析并配置翻译」：若名称未填则 toast 提示；否则调用 `acDeviceStateModal(draft.id, callback, draft.name)`，回调将生成结果写回草稿 `draft.runtime` 并更新文本框。

### 6. 工具与提示词（不做联动）

- 工具面板与提示词**互不联动**：加入 / 移除工具都不会改动提示词，面板也不会扫描提示词。
- 用户需在提示词中**自行书写**何时调用某工具（纯手写文本），这与工具列表是否包含该工具无强制关系。

## 五、执行阶段

- 保存时智能体数据（提示词 + 工具列表 + 各工具运行时配置）写入平台后端。
- 画布真实执行时从平台后端读取运行时配置，按配置执行工具及其后处理（如 `templateRender` 翻译）。

## 六、关键函数索引

- `acToolPanelDrawer()`：工具配置面板主体（渲染 + onMount 事件绑定），内部维护 draft/activeId 草稿态。
- `acGenToolId()`：生成行唯一 id（`'ut-'` + 时间戳 36 进制 + 随机串）。
- `acRemoveToolRow(id)`：从 `AC.usedTools` 剔除指定行并删除 `AC.toolRuntimeConfig[id]`。
- `acDeviceStateModal(rowId, onDone, dispNameArg)`：设备状态翻译弹窗，回调式写回（`onDone(out)`），标题展示 `dispNameArg`。
