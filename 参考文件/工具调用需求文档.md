# 工具调用需求文档

本文档说明「工具」配置面板的交互流程和数据来源。

## 一、数据来源

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| 可选工具全集 | 工具服务（麒哥）提供 | 当前端点可用的所有工具，含工具名、默认描述、入参、返回值等，用于右上角「添加工具」下拉 |
| 已配置的工具列表 | 用户在面板中配置 | 用户添加的工具，随智能体配置一起保存到平台后端（威哥） |
| 运行时配置 | 用户在面板中配置 | 某个工具执行时的额外处理规则（如设备状态翻译），随工具一起保存 |

> 每个已配置工具包含：工具名（沿用底层工具名，不可改）、描述（可改，留空则用默认描述）、入参（只读，来自工具服务）、返回值（只读，来自工具服务）、运行时配置（可选，可改）。

## 二、入口

在提示词编辑区，「编写教程」左侧有「工具配置」文字入口，点击打开右侧抽屉面板。

## 三、面板结构

面板顶部为标题栏：左侧标题「工具」，右上角固定「添加工具」按钮（无论是否已有工具都在此处添加）。

标题栏下方主体区域有两种状态：

- **空态（还没有任何工具）**：主体区居中显示一行文字提示「暂无工具，请点击右上角『添加工具』」，不分左右框，主体区**不再单独放添加按钮**（右上角已足够）。
- **常规态（已有工具）**：分左右两栏。
  - **左侧**（约 220px）：已配置的工具列表，每项单行显示工具名；工具名右侧**常显**一个叉号（`fa-times`），点击删除该工具。
  - **右侧**：当前选中工具的详情表单（见下）。

### 右侧详情表单字段

从上到下依次为：

| 字段 | 是否可改 | 说明 |
| --- | --- | --- |
| 工具名 | 只读 | 展示所选底层工具名，灰底只读框 |
| 描述 | 可改 | 多行输入，留空时确定后自动填入默认描述 |
| 入参 | 只读 | 横向卡片式展示，每个参数为一张圆角卡片，含「参数名 + 类型（浅灰）+ 必填红星 `*`」，自动换行；无入参时显示「无入参」 |
| 返回值 | 只读 | 等宽字体灰底框展示返回类型 |
| 运行时配置 | 可改 | 多行 JSON 编辑区，工具执行后的额外配置（如状态码转译模版、字段映射等） |

底部仅有一个「确定」按钮（**无取消按钮**）。

**打开面板时**：

- 若已有配置好的工具，自动选中第一个并在右侧展示其详情；
- 若还没有任何工具，展示上述空态提示。

## 四、核心交互

### 1. 添加工具（选中即入列表）

点击右上角「添加工具」，按钮下方弹出下拉面板，每个选项显示两行：**工具名 + 默认描述**，方便识别，数据来自「可选工具全集」。

**点击某个选项后立即生效**：该工具直接加入左侧列表（描述取默认描述），并自动选中、在右侧进入编辑态。无需再在表单内二次选择工具。

点击面板空白处会收起下拉。

### 2. 编辑描述 / 运行时须点确定才保存

工具加入列表后，可修改「描述」和「运行时配置」。这两项的编辑先暂存为「草稿」，只有点击「确定」后才真正回写到工具列表。**如果没点确定就切换到其他工具或关闭面板，本次对描述/运行时的修改会丢弃。**

> 注意：工具名、入参、返回值均为只读，不参与编辑与草稿。

### 3. 确定

点击「确定」后：

- 回写描述与运行时配置到当前工具；
- **若描述留空，自动填入所选工具的默认描述**；
- **保存成功后在抽屉内居中弹出「已保存」提示**（提示居于抽屉面板中央，而非整个页面中央），右侧继续展示当前工具内容。

无必填校验拦截（工具名固定、描述可空），点确定即保存。

### 4. 切换工具

点击左侧列表其他工具即切换到该工具的编辑态；若当前工具有未确定的草稿改动，切换后草稿丢弃。

### 5. 删除

点击左侧工具名右侧的叉号（常显，无需悬停），弹出二次确认。确认后从列表移除（其运行时配置一并删除）：

- 若列表还有其他工具，右侧回落到第一个工具；
- 若列表已空，主体区回到空态提示。

### 6. 运行时配置

运行时配置区始终显示，为多行 JSON 编辑区。可手动编写，也可通过设备状态翻译弹窗生成后写回。（详见《设备状态上报翻译需求文档》）

## 五、工具与提示词不联动

工具面板与提示词**互不影响**：添加或删除工具都不会改动提示词。用户需要在提示词里**自己写明**何时调用哪个工具，且调用的工具范围要落在已配置的工具列表内。

## 六、保存与执行

- 用户保存时，工具列表和各自的运行时配置随智能体配置一起存到平台后端（威哥）；
- 画布真实执行时，从平台后端读取配置，按运行时配置执行工具及其后处理（如状态翻译）。
